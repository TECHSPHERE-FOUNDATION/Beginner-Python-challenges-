# How to Submit Challenges

1. Open the TechSphere challenge repository.
2. Click the Fork button.
3. Select your personal GitHub account.
4. Open your forked repository.
5. Open the appropriate challenge folder.
6. Create a folder with your GitHub username.
7. Upload your solution file into that folder.
8. Commit your changes to a new branch.
9. Click Contribute → Open pull request.
10. Check your submission and click Create pull request.
